# Introduction
This project is a operating system focusing on privacy and security with high performance.
It currently includes a bootloader, terminal/shell and programming language.

# System 079
The operating system currently consisting of a bootloader.

# ChaosGUI
The terminal/shell for the OS and other systems like linux. It comes with standard libraries and tools.

# ChaosLang
A programming language for both high and low level dev.
