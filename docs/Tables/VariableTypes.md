# Variable Types
## int
4 byte integer number. Syntax:

    int x;

## char
1 byte number/character. Syntax:

    char c;

## float
4 byte floating point number. Syntax:

    float f;

## double
8 byte floating point number. Syntax:

    double d;

## long double
16 byte floating point number. Syntax:

    long double ld;
